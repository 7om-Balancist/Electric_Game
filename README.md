# 循迹小车（8 路灰度 + PI 位置闭环 + L 形直角状态机）

MSPM0G3507 上的灰度巡线小车。核心是一条 **5 ms 硬实时控制链**：串行灰度采样 →
加权质心定位 → 位置 PI → 差速 PWM，并带直角弯状态机、丢线保护、蓝牙在线调参。

---

## 1. 控制链

```
5ms 定时器中断 (CTRL_TIMER)
   ├─ 编码器测速      (counts 差 × 200 → pulses/s)
   ├─ 灰度采样        (PB6 CLK / PB7 DAT, 串行移位读出 8 bit)
   ├─ 加权质心        (+120/+70/+40/+30 | -30/-40/-70/-120)
   ├─ 状态机          NORMAL / TURN_L / TURN_R
   ├─ 位置 PI         KP=2.0  KI=0.3  KD=0   dt=0.005  → 限幅 ±1000
   └─ 差速输出        L = BASE+steer,  R = BASE−steer   (BASE=700)
```

**为什么用加权质心而不是"数到第几路"**：8 路数字量的中点只有 7 个档位，跳变就是 100 的台阶，
位置环会跟着抖。加权后中心附近权重小（±30）、外侧权重大（±120），
黑线居中时 pos=0，偏移时连续变化，PI 才有意义。

**为什么只有 PI 没有 D**：灰度是离散量，单帧跳变会被 D 项放大成噪声；积分项负责消除
"小车斜着走"造成的稳态偏差。另有转向增量限幅 ±100/周期，防止电机猛跳。

---

## 2. 直角弯状态机

```
NORMAL ──检测到"最外侧一路黑 + 对侧四路全白"──▶ TURN_L / TURN_R
   ▲                                                  │
   └── 中间两路至少 2 路黑（转到位）或超时 ─────────────┘
```

| 参数 | 值 | 作用 |
|---|---|---|
| `TURN_MIN` | 100 ms | 最短保持，防止刚进直角就被判"转完" |
| `TURN_HOLD` | 250 ms | 最长保持，兜底防止卡死在转弯态 |
| `TURN_SPEED` | 500（蓝牙可调） | 原地差速转向 PWM |
| `LOST_MS` | 200 ms | 全白（丢线）时先保持上次转向，超时才停车 |

丢线不是立刻停：先**保持最后一次有效转向量**继续找线，200 ms 内没找回才刹车。
这在过弯、过缝时能避免"一丢线就原地停死"。

## 3. 硬件接线

| 功能 | 外设 | 引脚 |
|---|---|---|
| 灰度 CLK / DAT | GPIO | PB6 / PB7 |
| 左电机 PWM / 右电机 PWM | TIMG0 CCP0 / CCP1 | PA12 / PA13（timerCount 4000） |
| 左电机 DIR | GPIO | PB19(L_DIR1) / PB17(L_DIR2) |
| 右电机 DIR | GPIO | PA16(R_DIR1) / PB24(R_DIR2) |
| 左编码器 A/B | GPIO | PA27 / PA26 |
| 右编码器 A/B | GPIO | PA14 / PA25 |
| 蓝牙 HC-05 | UART3 | PB2(TX) / PB3(RX)，38400 |
| JY61P 陀螺仪 | UART0 | PA17 / PA18 |
| ILI9341 TFT | SPI | PB8=MOSI, PB9=SCK, PB10=RES, PB11=DC, PB14=CS, PB13=BLK |
| 红外测距 | ADC1 | PA15（2.5 V 内部参考） |
| 蜂鸣器 | GPIO | PA7 |

TB6612 真值表：`IN1=H, IN2=L` 正转；`IN1=L, IN2=H` 反转；`L/L` 短接刹车；`H/H` 停止。

## 4. 蓝牙在线调参

HC-05 接 UART3，文本协议，一条命令改一个参数，**改完立即重建 PID 并生效，不用重烧固件**：

| 参数 | 含义 | 默认 |
|---|---|---|
| `KP` / `KI` | 位置环比例 / 积分 | 2.0 / 0.3 |
| `BASE_PWM` | 直行基准 PWM | 700 |
| `TURN_SPEED` | 直角转弯 PWM | 500 |
| `OUTPUT_LIM` | 转向量限幅 | 1000 |

这是整个工程里最实用的一处设计：**把"改一个数 → 编译 → 烧录 → 放车 → 试跑"的循环
压缩成"手机发一条消息"**，赛道边就能调。

## 5. 调试显示

ILI9341（320×240）分四块实时显示：

- 顶部 8 个色块 = 8 路灰度原始值（黑白直观可见）
- `St:` 状态机 + 位置质心值
- `IR:` 红外测距
- `Spd:` 左右轮速（pulses/s）、`Yaw:` JY61P 航向角

刷新做了降频（每 50 次控制周期刷一次 UI），避免 SPI 刷屏拖慢 5 ms 控制链。
`oled.c` 备用（SSD1306），当前走 TFT。

## 6. 已知限制 / 可改进

1. **`KD` 恒为 0**：结构上支持微分，实际靠积分 + 限幅抑制超调。若能拿到可靠的连续位置微分（比如提高灰度采样率），加 D 会明显改善过弯响应。
2. **直角判定依赖固定时序**（100~250 ms）：对转速变化敏感，换电池电压下降后可能需要重调。更稳的做法是结合编码器里程或陀螺仪 yaw 增量。
3. **速度环未闭环**：`g_speed_l/r` 只用于显示，没有参与控制；目前是"开环差速 + 位置补偿"。加一层轮速 PI 能显著改善直线稳定性。
4. **灰度串行读取在 5 ms 中断里同步完成**：会占用中断时间，可考虑改成定时器触发 + 状态机异步读取。
